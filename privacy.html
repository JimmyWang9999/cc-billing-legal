隱私權政策 Privacy Policy

最後更新：2026-09-26

1. 適用範圍

Credit Card Billing（以下稱「本工具」）僅供擁有者本人使用，唯一授權的 Google 帳號為擁有者自己的帳號。

2. 存取的資料

  • Gmail（唯讀）：僅搜尋並下載特定銀行寄來的信用卡帳單郵件附件。
  • Google Drive：在擁有者的 Drive 中建立與更新「Credit_Card_Billing」資料夾內的帳單、設定與結果檔案。

3. 資料的使用與分享

資料僅用於產生擁有者自己的消費明細與彙總，並透過擁有者自己的 Telegram Bot 通知擁有者本人。本工具不會出售、分享或轉移任何資料給第三方，也不將資料用於廣告或其他用途。

4. 資料保存與刪除

帳單與結果檔案保存在擁有者自己的 Google Drive，由擁有者自行管理與刪除。擁有者可隨時於 Google 帳戶權限設定 撤銷本工具的存取權。

5. Google API 服務使用者資料政策

本工具對 Google API 取得之資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

This tool is used solely by its owner. It reads (read-only) the owner's own credit card statement emails in Gmail and stores files in the owner's own Google Drive. Data is used only to produce the owner's personal spending summary, is never sold or shared with third parties, and can be removed by the owner at any time. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
